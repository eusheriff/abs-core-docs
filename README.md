# ABS Core Documentation

Documentation for [ABS Core](https://abscore.app), the Agent Behavior System kernel.

## Overview

This repository hosts the official documentation for ABS Core. It is deployed automatically to our documentation site.

- **Site:** [docs.abscore.app](https://docs.abscore.app) (or configured domain)
- **Status:** Public Documentation

## Structure

- `features/`: Core governance engine features (Policy Engine, Secret Vault, etc).
- `policies/`: Standard policy packs (Financial, HIPAA, LGPD).
- `sdk/`: SDK documentation for Node.js, Python, and VS Code.
- `api-reference/`: OpenAPI specifications and endpoint details.

## Contribution

This content is synchronized from the private `abs-core` monorepo. Direct edits here may be overwritten. Please submit issues if you find discrepancies.
