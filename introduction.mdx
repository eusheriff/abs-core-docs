## Why ABS Core?

AI agents are increasingly autonomous — writing code, making API calls, accessing databases. **Without governance, every agent is a liability.**

| Problem | ABS Solution |
|---------|-------------|
| Agent sends PII to external API | **Policy Engine** blocks in <5ms |
| Agent credentials leaked in logs | **Secret Vault** injects at runtime (JIT) |
| Agent stops responding | **Heartbeat Sentinel** detects in 5 minutes |
| Compliance audit required | **Immutable Ledger** with hash chain |
| New attack vector discovered | **CHI** classifies intent semantically |
